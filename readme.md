# Luminous Markdown Editor
**Beautifully render and edit your Markdown files.**

**Drag & drop a file, or get started with the buttons.**

**Enjoy!**

**Use**
- **luminous-md-editor.html**

The Chrome version uses a different file system.

Open the HTML file in Chrome or Edge and click the folder icon.

1: Select the folder containing the Markdown file and images.

2: If there are multiple Markdown files in the folder, select one by its number.

3: Press Ctrl+S to overwrite the original file.

4: Press Ctrl+Shift+S to save a copy with a different name in the same folder.
